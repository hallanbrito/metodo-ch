# The CHAVE Cycle

Every W Slice goes through five movements. Small changes may go through them quickly; critical changes may require formal documentation.

| Step | Movement | Expected outcome |
|---|---|---|
| **C** | Contextualize | Read the source of truth; understand the need, risk, history, and current capabilities. |
| **H** | Harmonize | Align intent, architecture, constraints, and criteria; record decisions and close the execution contract. |
| **A** | Act | Delegate to a suitable agent in an isolated environment, with bounded autonomy and time. |
| **V** | Verify | Examine evidence, diffs, tests, security, scope adherence, and documentation impact; correct or reject as needed. |
| **E** | Evolve | Obtain human acceptance, integrate, clean temporary resources, and return lessons to versioned memory. |

## Operational rule

No previous chat replaces the **published baseline**. Context must be rebuilt from the current source of truth before a new execution.

CHAVE is not a sequence used to justify implementation after the fact. **H — Harmonize** exists to prevent unresolved decisions from being silently made during **A — Act**.

*The acronym retains its original Portuguese spelling; the English step names convey the same sequence.*
